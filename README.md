# NodeTrace

Новая версия сайта R&D-студии электроники. React + TypeScript + Vite, локальные шрифты и изображения, статическая прерисовка HTML для поисковых систем. Готов к публикации на GitHub Pages без отдельного сервера.

## Локальный запуск

```bash
npm ci
npm run dev
```

Сборка готового сайта:

```bash
npm run build
npm run preview
```

Результат находится в каталоге `dist/`. Во время сборки главная страница дополнительно прерисовывается в HTML.

## Публикация на GitHub Pages

### Первый запуск

Для публикации нужен только [Git для Windows](https://git-scm.com/download/win). Node.js на компьютере не обязателен: сборку выполняет GitHub Actions.

1. Склонируйте существующий репозиторий:

   ```bash
   git clone https://github.com/khrenok/.github.io.git nodetrace-site
   ```

2. Скопируйте **все файлы этого проекта** в получившуюся папку `nodetrace-site` с заменой. В том числе нужны скрытые каталоги `.github` и файл `public/.nojekyll`.
3. В репозитории откройте **Settings → Pages → Source → GitHub Actions**. Это делается один раз.
4. У регистратора домена оставьте DNS-записи GitHub Pages. Файл `public/CNAME` уже содержит `nodetrace.ru` и автоматически попадает в каждую сборку.

### Следующие обновления — одним двойным щелчком

1. Измените файлы сайта в папке репозитория.
2. Запустите **`publish.cmd`** двойным щелчком.
3. Скрипт сам выполнит `git add`, `git commit` и `git push origin main`.
4. Дождитесь зелёной отметки **Deploy to GitHub Pages** на вкладке **Actions** репозитория. После неё обновится `https://nodetrace.ru`.

Если изменений нет, скрипт завершит работу без пустого коммита. Локально устанавливать зависимости и запускать сборку перед публикацией не нужно.

## Поисковые системы

Уже включены в проект:

- `public/CNAME` — закрепляет домен `nodetrace.ru` за GitHub Pages;
- `public/robots.txt` — разрешает индексацию и содержит адрес Sitemap;
- `public/sitemap.xml` — карта главной страницы; дата `lastmod` автоматически обновляется при каждой сборке;
- `public/.nojekyll` — отключает обработку Jekyll на GitHub Pages;
- `public/yandex_7685266b99ac4093.html` — перенесённое из действующего репозитория подтверждение Яндекс Вебмастера;
- canonical, description, Open Graph, Twitter Card и Organization JSON-LD в `index.html`;
- статическая прерисовка содержимого в HTML во время `npm run build`.

Сборка специально проверяет наличие `CNAME`, `robots.txt`, `sitemap.xml`, `.nojekyll` и HTML-файла подтверждения Яндекса, чтобы случайно не опубликовать сайт без них.

### Яндекс Вебмастер — уже перенесён

Из действующего репозитория без изменений скопирован файл `yandex_7685266b99ac4093.html`. После публикации он будет доступен по адресу:

`https://nodetrace.ru/yandex_7685266b99ac4093.html`

Никакой новый код или метатег добавлять не нужно. Не удаляйте этот файл при следующих обновлениях: Яндекс периодически повторяет проверку прав. В Вебмастере останется только указать Sitemap, если это ещё не сделано: `https://nodetrace.ru/sitemap.xml`.

Официальная инструкция: [Подтверждение прав на сайт](https://yandex.ru/support/webmaster/ru/service/rights.html).

### Google Search Console

Добавьте ресурс `https://nodetrace.ru`, подтвердите права предложенным способом и отправьте тот же Sitemap: `https://nodetrace.ru/sitemap.xml`. Отдельный Google-файл в проекте не нужен до получения вашего персонального кода или HTML-файла подтверждения.

## Заявки

Форма использует прежний Formspree endpoint: `https://formspree.io/f/mvzjrkgn`.

Поля: имя, email, компания/проект, формат работы и описание задачи. JavaScript добавляет индикатор отправки, обработку ошибок и сообщение об успехе. Без JavaScript форма продолжает работать обычной POST-отправкой через Formspree.

Перед публикацией убедитесь, что в кабинете Formspree разрешён домен `nodetrace.ru`, если включено ограничение доменов.

## Основные каталоги

- `src/pages/Home.tsx` — структура и секции страницы;
- `src/data.ts` — услуги, проекты, тарифы и показатели;
- `src/components/` — навигация, форма и карточка проекта;
- `src/index.css` — дизайн-система и адаптивность;
- `public/images/` — оптимизированные маскот, логотип и Open Graph;
- `.github/workflows/deploy.yml` — автоматическая публикация.
